# Agent Team Dashboard

智能体团队任务台 - 你的 AI 程序员团队协作可视化工具

## 🎯 目标

打造一个可视化的 Agent Team 管理系统，让多个 AI Agent 可以分工协作完成任务。

## 🏗️ 技术栈

- **前端**: React + Vite + TypeScript
- **样式**: Tailwind CSS
- **可视化**: React Flow
- **状态**: Zustand
- **后端**: FastAPI + SQLite

## 📦 模块

- 仪表盘 - 任务概览
- Agent 管理 - 添加/编辑/删除智能体
- 团队视图 - 可视化协作关系
- 任务面板 - 任务分配与进度

## 🎮 最终目标

使用搭建的 Agent Team 实现一个完整的小游戏
